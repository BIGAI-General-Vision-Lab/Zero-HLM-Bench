# Cosmos-Reason2 Processor Resources

Configuration and tokenizer resources for [NVIDIA Cosmos-Reason2-2B](https://huggingface.co/nvidia/Cosmos-Reason2-2B), based on Qwen3-VL. No Cosmos model weights are included here.

These resources retain the NVIDIA Open Model License supplied with the upstream model. The license text is in `../licenses/Cosmos-Reason2-NVIDIA-Open-Model-License.md`; [the upstream terms](https://www.nvidia.com/en-us/agreements/enterprise-software/nvidia-open-model-license/) govern their use.
